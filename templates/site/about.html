About

I am a developer in Italy. I work mostly on the backend — pipelines, APIs, the deployment underneath them — and I go as far up the stack as a project needs, which in practice has meant Next.js, Vue and React Native as well.

How I tend to work

Nearly everything on this site started as a chore. Re-reading rental listings every morning. SSHing into a server to find out whether anything had fallen over. A festival committee coordinating hundreds of bookings by phone. The interesting part is rarely the technology — it is noticing that a task repeats and is therefore something a machine should be doing.

I keep dependencies low when the thing has to be reliable: the agent that monitors my server has none, the rental scraper has three. I write the documentation as I go, because every one of these projects has a moment six months later where I have entirely forgotten how it works. And I put a human review step in front of anything a model produces before it becomes irreversible — a habit from the invoice pipeline that has not steered me wrong since.
